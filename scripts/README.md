# scripts/

Standalone automation utilities (Handbook Appendix A.13) — not business
logic, and not part of the Streamlit app. Each script does one job and is
runnable directly, e.g. `python scripts/train_model.py`.

Planned scripts (added as their corresponding milestone is implemented):
`setup_environment.py`, `download_dataset.py`, `preprocess_dataset.py`,
`train_model.py`, `evaluate_model.py`, `generate_reports.py`,
`cleanup_outputs.py`.
