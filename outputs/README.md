# outputs/

Generated artifacts only — nothing here is source code or permanent
application logic (Handbook Appendix A.8).

| Folder | Purpose |
|---|---|
| `forecasts/` | Prediction results (CSV). |
| `reports/` | Generated PDF/HTML reports. |
| `charts/` | Saved visualization images. |
| `exports/` | User-triggered CSV/Excel exports. |
| `logs/` | Execution logs (git-ignored; see `.gitignore`). |
| `performance/` | Evaluation reports and benchmark summaries. |

Temporary files here should be pruned periodically; only approved reports and
performance summaries are meant to be permanent.
